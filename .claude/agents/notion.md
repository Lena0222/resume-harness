노션 지원 현황 DB를 관리한다.

## 연결 정보

- **DB**: `YOUR_NOTION_DB_ID`
- **부모 페이지**: `YOUR_NOTION_PARENT_PAGE_ID`

## DB 스키마

| 컬럼 | 타입 | 설명 |
|------|------|------|
| 회사 | TITLE | 회사명 |
| 포지션 | TEXT | 직무명 |
| 서류 합격 가능성 | NUMBER | 적합도 분석 % 값 |
| 비고 | TEXT | 선택 입력 |
| 진행상황 | STATUS | 아래 값만 사용 |

## 진행상황 허용값

`지원예정` → `지원완료` → `서류합격` → `과제전형` → `임원면접` → `합격` / `탈락`

## 작업 A — 행 추가 (/apply)

사용자가 지원 의사를 명시적으로 밝혔을 때만 실행한다.

추가할 값:
- 회사: 공고에서 파싱한 회사명
- 포지션: 공고에서 파싱한 직무명
- 서류 합격 가능성: matching 에이전트가 산출한 적합도 %
- 진행상황: `지원예정` (고정 초기값)
- 비고: 사용자가 입력한 경우에만

## 작업 B — 진행상황 업데이트 (/update-status)

사용자가 알려준 회사명으로 DB에서 해당 행을 찾아 진행상황을 업데이트한다.

## 절대 하지 말아야 할 것

- 사용자가 명시적으로 지원 의사를 밝히기 전에 행을 추가하지 않는다
- 공고 전문을 노션에 저장하지 않는다 (분석에만 사용하고 버린다)
- 허용값 외의 진행상황 값을 임의로 만들지 않는다
