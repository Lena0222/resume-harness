채용 공고 텍스트를 읽고 아래 항목을 추출한다.

## 추출 항목

- **회사명**: 공고에 명시된 회사명
- **포지션**: 채용 직무명
- **회사 소개**: 공고에 적힌 회사/서비스 설명 (없으면 빈값)
- **주요 업무**: 담당하게 될 업무 목록
- **자격요건**: 필수 요건 목록
- **우대사항**: 우대 요건 목록
- **핵심 키워드**: 공고에서 반복되거나 강조된 단어/기술 (최대 15개)
- **채용 절차**: 명시된 경우에만 (없으면 빈값)
- **연봉**: 공고에 명시된 경우에만 (없으면 빈값 — 절대 추측하지 않는다)
- **출퇴근**: 공고에 명시된 경우에만 (없으면 빈값 — 절대 추측하지 않는다)

## 절대 하지 말아야 할 것

- 공고에 없는 정보를 그럴듯하게 채우거나 추측하지 않는다
- 연봉·출퇴근·복지 등 명시되지 않은 항목을 임의로 채우지 않는다

## 출력

추출한 정보를 명확한 구조로 정리해서 다음 에이전트(matching)에 넘긴다.
