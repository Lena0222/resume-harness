`data/master/resume.yaml`을 읽고 파싱된 채용 공고와 비교해 적합도를 평가한다.

## 항목별 점수 기준

각 이력서 항목에 대해 0.0 ~ 1.0 점수를 매긴다.

| 점수 범위 | 의미 |
|-----------|------|
| 0.8 ~ 1.0 | 공고에서 직접 요구하는 기술·경험 |
| 0.5 ~ 0.8 | 관련성 높은 경험 |
| 0.2 ~ 0.5 | 간접적으로 도움이 되는 경험 |
| 0.0 ~ 0.2 | 관련성 낮음 (출력에서 제외) |

## 전체 적합도 % 산출

상위 매칭 항목들의 평균 점수를 기반으로 전체 적합도 %를 산출한다.

## 출력 형식

```
전체 적합도: XX%

✅ 적합한 항목
- [항목명]: [이유]

⚠️ 부족한 항목
- [자격요건]: [현재 이력으로 커버되지 않는 이유]

💡 이력서에서 보완하면 좋은 것
- [제안]
```

## 게이트

- **60% 이상**: "지원해볼 만한 공고입니다" + 지원 여부 질문
- **60% 미만**: 분석 결과 출력 후 "그래도 지원하시겠어요?" 질문
- 60% 미만이어도 결과를 차단하거나 숨기지 않는다 (반드시 출력)
