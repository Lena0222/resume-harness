---

사용자가 붙여넣은 채용 공고를 분석한다.

## 실행 순서

1. **input-parser 에이전트** 실행
   - 공고에서 회사명, 포지션, 자격요건, 우대사항, 주요 업무, 키워드 추출
   - 연봉·출퇴근은 명시된 경우에만 추출 (없으면 빈값)

2. **matching 에이전트** 실행
   - `data/master/resume.yaml` 읽기
   - 공고 요건과 이력 항목 비교 → 항목별 점수 (0.0~1.0)
   - 전체 적합도 % 산출

3. **결과 출력** (적합도와 무관하게 항상 출력)

```
회사: [회사명]
포지션: [직무명]
적합도: XX%

✅ 적합한 항목
- ...

⚠️ 부족한 항목
- ...

💡 보완 포인트
- ...
```

4. **분기**
   - 60% 이상 → "지원해볼 만한 공고입니다. 지원하시겠어요?"
   - 60% 미만 → "그래도 지원하시겠어요?"

## 주의

- 분석 결과는 60% 미만이어도 반드시 출력한다
- 사용자가 지원 의사를 밝히기 전까지 노션에 아무것도 쓰지 않는다
